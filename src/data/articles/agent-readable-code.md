人可以凭经验在陌生仓库里寻找入口，Agent 则更依赖可以被搜索和验证的结构。

当模块名称含糊、契约散落、生成文件与事实源混在一起时，Agent 不得不读取更多文件、消耗更多上下文，也更容易在错误的位置修改代码。

## 可发现性是一种工程能力

稳定的命名、明确的模块入口和靠近代码的验证命令，会显著降低理解成本。它们不仅帮助 Agent，也帮助刚加入项目的人。

让代码可被 Agent 阅读，并不是为了迎合模型。它是在迫使系统把隐含知识变成可以查找、可以说明、可以验证的结构。
